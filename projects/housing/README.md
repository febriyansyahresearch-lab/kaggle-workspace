# Housing — Regression (Price Prediction)

**Dataset:** California Housing (synthetic)  
**Models:** Linear Regression, RandomForest, Gradient Boosting  

## Methodology

1. **Data Generation**: 500 records with 8 features
2. **Models**: Compare 3 algorithms (Linear, RF, GBR)
3. **Evaluation**: RMSE, R² score

python -m projects.housing.src.train
