# Customer Segmentation — Unsupervised Learning

**Dataset:** Customer data (300 records, 4 features)  
**Algorithm:** K-Means with PCA visualization  

## Methodology

1. **Data Generation**: 3 customer clusters with distinct profiles
2. **Clustering**: K-Means with elbow method for optimal k
3. **Dimensionality Reduction**: PCA for 2D visualization
4. **Evaluation**: Inertia, explained variance

## Usage

```bash
python -m projects.clustering.src.cluster
```
